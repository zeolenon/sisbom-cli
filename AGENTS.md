# Instruções para agentes — SISBOM CLI

Leia [o guia completo](docs/guia-agentes.md) e --help dos comandos reais. Use HTTP/CLI; não extrair cookies/tokens. Não renovar login sem autorização.

Leituras não autorizam escrita/divulgação. RI somente manuais pendentes mediante lote autorizado; voluntariado-inscrever permite inclusão própria explícita com diário e conferência; retirada/substituição e exportação continuam desabilitadas. SISDO prévia padrão/--executar; férias mutante padrão/--dry-run para prévia. E-Funcional usa mutation de impressão; raw GraphQL pode escrever.

Preserve checkout sujo, sessões, estados/locks e alterações de terceiros. Não versionar pessoal/documentos/credenciais/artefatos operacionais reais. Fixtures sintéticas. Após timeout reconciliar antes de retry. Erro de sessão/HTTP não é zero registros.

Teste python -m unittest discover -s tests -v, build/instalação limpa e smoke dos comandos registrados. Documentar adições. Build/CI sem produção. Respeitar branch/PR/proteções; release depois de conferir CI/commit/tag/assets.
